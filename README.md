# Escolinha Municipal SECTI

Sistema web desenvolvido para facilitar as inscrições de alunos nas modalidades esportivas e auxiliar a equipe administrativa no gerenciamento das atividades da Escolinha Municipal SECTI.

## Funcionalidades

- Página inicial com apresentação da escolinha.
- Exibição das modalidades esportivas.
- Inscrição de alunos pelos responsáveis.
- Painel administrativo para gerenciar modalidades e inscrições.
- Aprovação e acompanhamento de alunos inscritos.
- Indicadores gerais para facilitar o controle administrativo.

## Modalidades

- Futebol
- Basquete
- Vôlei
- Natação
- Karatê

## Tecnologias

- PHP
- JavaScript
- HTML5 e CSS3
- PostgreSQL / Supabase
- Docker
- Vercel
